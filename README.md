# Treshan Rao Ganni — Resume Website

A static HTML + CSS resume website for the IIMB BBA (DBE) course.

## Files
- `index.html`: Website content and semantic HTML
- `styles.css`: External CSS styling
- `images/profile.jpg`: **Add your own professional portrait here** (not supplied)

## Preview locally
Open `index.html` in a web browser. No server or JavaScript is required.

## Publish using GitHub Pages
1. Create a public GitHub repository, e.g. `resume-website`.
2. Upload `index.html`, `styles.css`, and the `images` folder (with your photo named `profile.jpg`).
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, `main`, and `/ (root)`; click **Save**.
5. Once published, the website should be at `https://YOUR-USERNAME.github.io/resume-website/`.

## CSS Module 4 concepts
External CSS, selectors (element, class, ID), colours, Google Fonts and fallback fonts, box model (margin, padding, border), cascade and specificity, combined selectors, pseudo-classes (`:hover`), pseudo-elements (`::after`), inheritance, `span`, display (`grid`, `flex`, `inline-block`), sticky/relative/absolute positioning, clear and responsive media queries.

Expandable sections use native HTML `<details>` and `<summary>` elements, so no JavaScript is necessary.

**Privacy:** This is a public portfolio. Remove your phone number from `index.html` if you don't want it visible online.
